## setUp for whole project

open vs code, clone this REPO there then:
    
    backend:
       1.] open new terminal
       2.] cd backend
       3.] npm i
       4.] create .env file in your backend folder, and paste this-
                                                   (MONGODB_URI= your connectionDb string without double quotation marks)
       5.] npm run dev

    frontend:
       1.] open new terminal-(not the backend terminal), It should be new
       2.] cd frontend
       3.] npm i
       4.] npm run dev
